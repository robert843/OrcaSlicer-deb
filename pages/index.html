OrcaSlicer APT Repo

Unofficial .deb packages for Debian, Ubuntu & Mint. Automatically built from official AppImage releases.

Auto-updated daily GPG signed amd64

⚡ Quick Install

One command to add the repo and install OrcaSlicer:

terminal 
wget -qO- REPO_URL/install.sh | sudo bash && sudo apt install orcaslicer

🔧 Manual Setup

Add the GPG signing key

terminal 
wget -qO- REPO_URL/public.asc | sudo tee /etc/apt/keyrings/orca-slicer.asc >/dev/null

Add the repository source

terminal 
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/orca-slicer.asc] REPO_URL stable main" | sudo tee /etc/apt/sources.list.d/orca-slicer.list >/dev/null

Update & install

terminal 
sudo apt update && sudo apt install orcaslicer
💡

After installation, updates come through the standard apt update && apt upgrade flow.

▶ Usage

Launch from terminal or your desktop application menu:

terminal 
orca-slicer

The application is installed to /opt/OrcaSlicer/.

🗑 Uninstall

terminal 
sudo apt remove orcaslicer
sudo rm /etc/apt/sources.list.d/orca-slicer.list
sudo rm /etc/apt/keyrings/orca-slicer.asc
