OrcaSlicer APT Repository

Unofficial .deb packages for Ubuntu/Debian/Mint — automatically built from official AppImage releases.

Quick Install

Run this one-liner to add the repository and install OrcaSlicer:

curl -fsSL REPO_URL/install.sh | sudo bash && sudo apt install orcaslicer

Manual Setup

1Add the GPG key

curl -fsSL REPO_URL/KEY.gpg | sudo gpg --dearmor -o /usr/share/keyrings/orcaslicer.gpg

2Add the repository

echo "deb [signed-by=/usr/share/keyrings/orcaslicer.gpg] REPO_URL stable main" | sudo tee /etc/apt/sources.list.d/orcaslicer.list

If the repository is not GPG-signed yet, use [trusted=yes] instead of the signed-by option.

3Install

sudo apt update && sudo apt install orcaslicer

Usage

After installation, launch from the terminal or your application menu:

orca-slicer

Files are installed to /opt/OrcaSlicer/. Updates arrive automatically via apt update && apt upgrade.

Uninstall

sudo apt remove orcaslicer
sudo rm /etc/apt/sources.list.d/orcaslicer.list
sudo rm /usr/share/keyrings/orcaslicer.gpg
